 # 中国历史专版（China History Atlas）Spec
 
 ## 1. 项目定位
 
 在中国历史维度上复刻并强化现有世界格局地图的交互体验：以**朝代**为章节、以**疆域变化**为主线、以**政权关系**为补充，做一部可交互、可回放、可检索的中国历史地图专版。
 
 复用现有 `world-history-map` 的 Vite + React + D3-geo + world-atlas 技术栈，新增独立数据层与视图组件，最终通过 `/china` 路由或独立入口进入。
 
 ## 2. 目标与范围
 
 ### 2.1 时间范围
 
 从有文字可考的早期王朝开始，到今天：
 
 - 夏商周（约前 2070–前 256）——传说与早期国家形态，用不确定性标注
 - 春秋战国（前 770–前 221）——诸侯国并立
 - 秦（前 221–前 206）——统一帝国开端
 - 汉（前 206–220）
 - 三国两晋南北朝（220–589）
 - 隋（581–618）
 - 唐（618–907）
 - 五代十国（907–979）
 - 宋辽西夏金（960–1279）
 - 元（1271–1368）
 - 明（1368–1644）
 - 清（1644–1912）
 - 中华民国（1912–1949）
 - 中华人民共和国（1949–至今）
 
 ### 2.2 地理范围
 
 以中国本部为核心，辐射直接影响区域：
 
 - 中国本部（汉地十八省/现代省份）
 - 东北、蒙古高原、西域、青藏高原、云贵高原
 - 朝鲜半岛北部、越南北部、中亚七河地区等历史上曾受中原王朝控制或册封的区域
 - 海上贸易/朝贡节点：琉球、东南亚部分港口
 
 ### 2.3 核心功能
 
 1. **朝代时间轴**：横向朝代选择器，每个朝代可展开分段（早期/盛期/晚期等）。
 2. **年代切片与疆域图**：每个分段对应一个年份快照，地图按政权控制范围着色，**边界描黑**。
 3. **政权标签**：在地图上标注当前主要政权/国家的名字（如“西汉”“匈奴”“高句丽”）。
 4. **历史大事**：每个年代切片关联 4–8 件 featured 事件。
 5. **政权关系**：用连线表达战争、同盟、朝贡/隶属、和亲、贸易、对峙等关系，不同线型/颜色区分。
 6. **事件详情卡片**：点击事件后展示时间、地点、参与政权、影响、疆域变化。
 7. **播放回放**：按年代切片自动播放，地图渐变过渡。
 8. **搜索与筛选**：按事件类型、地区、政权、关键词检索。

 ## 4. 数据模型
 
 复用并扩展现有类型：
 
 ```ts
 // 朝代章节
 export interface ChinaChapter extends Chapter {
   dynasty: string;           // 朝代名
   capitals: string[];        // 都城
   majorEthnicGroups: string[];
 }
 
 // 年代切片
 export interface ChinaEraSlice extends EraSlice {
   year: number;              // 快照年份（可为负数表示公元前）
   dynastyStage: string;      // 如“盛唐”“晚唐”
   featuredEventIds: string[];
   relationIds: string[];     // 本切片活跃的国家关系
 }
 
 // 政权/国家
 export interface ChinaPolity extends Polity {
   nameZh: string;
   nameEn?: string;
   dynasty?: string;          // 所属朝代（可选）
   type: 'empire' | 'kingdom' | 'duchy' | 'tribe' | 'republic' | 'colonial' | 'other';
   capital?: string;
   ethnicGroup?: string;
   color: string;
 }
 
 // 历史事件
 export interface ChinaEvent extends WorldEvent {
   year: number;
   startYear?: number;
   endYear?: number;
   location?: string;         // 现代地名或古地名
   category: 'war' | 'treaty' | 'rebellion' | 'reform' | 'unification' | 'culture' | 'economy' | 'tech';
   polityIds: string[];       // 参与政权
   territoryChange?: string;  // 疆域变化描述
   relations?: RelationLink[];
 }
 
 // 政权间关系
 export interface RelationLink {
   from: string;              // polityId
   to: string;
   type: 'war' | 'alliance' | 'tribute' | 'marriage' | 'trade' | 'rivalry' | 'subordinate';
   startYear: number;
   endYear?: number;
   note?: string;
 }
 
 // 疆域归属规则：将现代国家/省份名映射到政权
 export interface ChinaPolityRule extends PolityRule {
   polityId: string;
   countryNames: string[];    // world-atlas 国家名或省份名
   provinces?: string[];      // 中国省级行政区（如需要更细粒度）
   from: number;
   to: number;
 }
 ```
 
 ### 4.1 疆域数据策略
 
 - **核心区域**：使用 `world-atlas` 中的国家边界 + 中国省级边界（如 TopoJSON 中中国省份数据可用则启用）。
 - **边疆与邻国**：用现代国家边界内填充表示历史上受中原政权控制或册封的区域（如唐安西都护府覆盖中亚部分国家）。
 - **不确定性**：夏商周三代控制范围用半透明/虚线边界或点状区域表示，并在说明中标注“考古与文献推论”。
 - **描黑边界**：所有渲染的国家/区域边界统一使用 `stroke: #1a1a1a; stroke-width: 0.5px`（高对比度），满足用户对“国界描黑”的要求。
 
 ## 5. 地图可视化方案
 
 ### 5.1 投影
 
 - 默认使用 **Asia-centric Natural Earth** 或 **Equirectangular** 投影，确保中国位于视口中心。
 - 允许用户切换：中国中心视图、东亚放大视图、全球视图。
 
 ### 5.2 图层
 
 1. **底图**：浅米色/浅灰色海洋与陆地。
 2. **疆域填充层**：按当前 `AttributionFrame` 给国家/省份填充政权颜色。
 3. **黑色边界线层**：所有国家/区域边界描黑。
 4. **关系连线层**：政权中心点之间的曲线，按关系类型着色/线型。
 5. **标签层**：政权名称标签，避免重叠，支持 hover 高亮。
 6. **事件标记层**：重要战役/事件发生地标注（如赤壁、淝水、钓鱼城）。
 
 ### 5.3 政权名称显示规则
 
 - 每个切片只显示**主要活跃政权**名称（重要性 ≥2 或有实际控制区）。
 - 标签放置在政权控制区的质心或首都坐标。
 - 小国/短暂政权可默认隐藏，hover 时显示。
 - 标签使用中文，字号根据政权控制面积缩放。
 
 ## 6. 关系网络可视化
 
 ### 6.1 关系类型与视觉编码
 
 | 关系类型 | 颜色 | 线型 | 示例 |
 |----------|------|------|------|
 | 战争 war | #d32f2f | 实线 + 箭头 | 汉匈战争、宋辽战争 |
 | 同盟 alliance | #1976d2 | 实线 + 双箭头 | 孙刘联盟、中俄密约 |
 | 朝贡/隶属 tribute/subordinate | #f9a825 | 虚线 + 箭头 | 明清朝贡体系 |
 | 和亲 marriage | #c2185b | 点线 | 汉匈和亲、唐蕃和亲 |
 | 贸易 trade | #388e3c | 细实线 | 丝绸之路、茶马互市 |
 | 对峙 rivalry | #7b1fa2 | 实线 + 双向箭头 | 南北朝对峙、冷战 |
 
 ### 6.2 交互
 
 - hover 关系线时高亮相关两个政权，并显示关系说明 tooltip。
 - 点击关系线打开详情弹窗，展示起止时间、事件、影响。
 - 支持按关系类型筛选开关。
 
 ## 7. 界面与交互
 
 ### 7.1 布局
 
 保持现有 App 的“地图舞台 + 左侧章节轨 + 底部时间轴 + 右侧/下方事件卡片”布局，但做朝代化改造：
 
 - **顶部**：标题“中国历史专版”、当前朝代/分段、搜索、筛选、视图切换。
 - **左侧章节轨**：纵向朝代列表，当前朝代高亮，点击展开分段。
 - **主地图**：占据屏幕中央，中国为中心。
 - **底部时间轴**：显示当前朝代内的分段节点，可拖拽/点击跳转。
 - **右下角/下方**：事件卡片流。
 - **右侧抽屉**：政权详情 / 事件详情。
 
 ### 7.2 新增组件
 
 - `DynastyRail`：朝代选择器（替换 ChapterRail）。
 - `ChinaMap`：中国专版地图组件（继承 WorldMap，改投影与描边）。
 - `RelationLayer`：关系连线层。
 - `PolityLabelLayer`：政权名称标签层。
 - `ChinaEventCard`：事件卡片（增加地点与参与政权）。
 - `RelationFilter`：关系类型开关。
 
 ### 7.3 播放模式
 
 - **分段播放**：按朝代内切片顺序自动切换，地图平滑过渡。
 - **事件播放**：按事件时间线播放，自动跳转到对应切片。
 - **关系动画**：关系连线可设置脉冲动画表示活跃关系。

 ## 9. 数据精度与边界说明
 
 - 古代疆域采用学界主流近似表达，争议地区标注为“控制/影响/册封”三级。
 - 台湾、西藏、新疆、内蒙古、东北等地区的历代归属按中国官方历史叙事与学界共识处理。
 - 夏商周控制范围用半透明表达不确定性。
 - 在“关于”面板中明确说明数据来源与精度限制。

 ## 11. 待确认问题
 
 1. **起点选择**：从夏商周开始，还是从秦统一开始？夏商周数据以传说/考古为主，精度较低，需要额外的不确定性表达。
 2. **疆域粒度**：是否需要精细到中国省级边界？`world-atlas` 默认不包含中国省份，如果需要，要引入额外的 TopoJSON 数据源。
 3. **周边政权**：是否重点显示匈奴、突厥、吐蕃、辽、金、蒙古、西夏、高句丽、朝鲜、越南、日本等？这些对关系网络很重要。
 4. **当代部分**：是否包含 1949 年之后的对外关系（如中苏同盟、中美建交、一带一路）？
 5. **台湾表述**：按中国官方叙事处理是否接受？
 6. **地图描黑**：是所有国家/区域边界都描黑，还是只描当前政权控制区边界？
 7. **部署形式**：作为现有项目的 `/china` 子页面，还是独立成一个新的历史地图站点？
 
 ## 12. 推荐额外特性
 
 1. **疆域面积估算**：在每个切片显示当前主要政权控制面积估算值（万平方公里）。
 2. **对比模式**：允许并排对比两个年份的疆域（如西汉 vs 唐）。
 3. **重要战役地图标记**：在地图上标注赤壁、淝水、钓鱼城、土木堡等战役位置，点击显示详情。
 4. **历史人物轨迹**：如张骞通西域、郑和下西洋、玄奘西行等路线的可视化。
 5. **朝代关系图**：非地图视图下，用力导向图展示当前切片的政权关系网络。
 6. **导出/分享**：生成当前年份地图的 PNG 图片或分享链接。
 7. **语音/朗读**：事件卡片支持语音朗读（浏览器 TTS）。
 8. **学习模式**：针对学生用户的测验模式（基于事件因果关系出题）。
 9. **史料出处**：每个事件标注史料来源（如《史记》《资治通鉴》《明实录》或现代研究）。
 10. **主题换肤**：提供“宣纸黄”“深夜青”“现代白”等视觉主题。
