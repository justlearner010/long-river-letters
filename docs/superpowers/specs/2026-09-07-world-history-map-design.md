# 世界格局变化：1300–2026 交互历史地图

状态：待审批  
日期：2026-09-07  
类型：静态 Web 应用设计规格

## 1. 背景与目标

做一个可本地运行的交互历史地图，演示 14–21 世纪世界格局变化。用户应能看到主要国家的领土变化、关键历史事件与发展脉络，既能自主探索，也适合用于演示和教学。

已确认的关键决策：

- 深度策略：全球视野 + 精选关键节点。
- 交互定位：可探索的交互页面，时间轴可拖动、可播放。
- 边界策略：较密年代切片，尽量还原主干边界，存疑处标注示意。
- 内容范围：综合文明史，政治军事为主线，同时包含经济、科技与文化事件。
- 内容编排：由开发方按通史共识筛选，用户通过审阅 spec 把关。
- 技术方案：本地静态 Web 应用（Vite + React + TypeScript + D3-geo）。
- 布局：垂直章节列表 + 中央地图 + 底部时间轴。
- 视觉风格：古籍羊皮纸风格。

## 2. 范围

### 2.1 做

- 1300–2026 年约 35 个年代切片，由 13 个历史章节组织。
- 沿时间变化的世界地图，以现代国家/主要行政区底图为基础，按“当时控制者”着色。
- 约 120 个关键事件，每个事件含年份、标题、100–200 字说明、章节归属、主题标签、影响地区与关联国家。
- 中国界面，历史名称保留英文或当地拼写。
- 章节切换、年份拖动/跳转、自动播放、地图悬停/点击、事件点击高亮、搜索与主题筛选。
- 每个章节 3–6 条主线事件，优先展示在地图下方的事件卡片中。
- 关于历史边界精度和数据来源的“说明”入口。
- 数据校验、组件测试、无头浏览器冒烟测试与本地构建。

### 2.2 不做

- 不追求逐年完整边界。
- 不做现代内部的省级行政区划级历史边界。
- 不做在线账号、实时数据同步或云端部署。
- 不做带争议性领土主张的自动判定；涉及争议地带时使用中性描述并在说明页提示。
- 不做多语言版本；英文仅作为历史名词的辅助拼写。

## 3. 使用场景

1. 教学演示：打开页面，选择一个章节，播放该章节的年份变化，配合章节总述和主线事件讲解。
2. 自主探索：拖动时间轴、点击国家或事件，查看领土归属与事件脉络。
3. 快速回顾：通过筛选器只看某一类事件，例如战争、条约、去殖民化、科技经济。

## 4. 信息架构与界面

### 4.1 页面布局（桌面）

- 顶部栏：产品名、当前年份、当前章节标题与一句话总述、搜索框、主题筛选入口、“说明”入口。
- 左侧栏：13 个垂直章节；当前章节高亮；每个章节可展开显示其年代切片。
- 中央区：羊皮纸世界地图；提供缩放、拖拽、悬停与点击。
- 底部条：年份滑块、播放/暂停、章节切片快速跳转。
- 事件卡片区：显示当前章节的 3–6 条主线事件。
- 右侧抽屉：点击国家或事件后打开，显示国家档案或事件详情；可关闭。

### 4.2 响应式规则

- 桌面（≥1200px）：四区完整布局。
- 平板（768–1199px）：左侧章节收窄为图标/短标签栏，右侧抽屉改为覆盖式。
- 手机（<768px）：章节改为横向可滚动的章节条，事件卡片叠在地图下方，右侧抽屉全屏覆盖。
- 地图容器在任意视口保持固定比例，不因内容撑破布局。

### 4.3 无障碍与键盘操作

- 章节、年份滑块、播放键、事件卡片均可被键盘聚焦。
- 方向键在章节/切片间移动；空格键播放/暂停；Esc 关闭抽屉。
- 地图关键信息在非图形区域有文本等价物（当前切片列表与事件列表）。
- 选中的章节、年份和筛选状态有足够的颜色/边框对比，不依赖单一颜色表达。

## 5. 视觉设计

### 5.1 羊皮纸风格

- 海洋底色：米色纸面系，例如 `#d8c8a3`。
- 大陆底纹：浅赭与浅灰绿相间，体现纸面质感。
- 边界线：深棕墨色，主线边界略粗，次要边界细线。
- 信息面板：半透明白纸色背景，深棕文字。
- 主题色：纸张黄、墨棕、朱砂红用于强调事件，靛青用于选中态，金赭色用于当前年份标记。
- 标题字体使用衬线感字体，正文使用系统中文字体，不依赖网络字体。

### 5.2 地图信息层级

- 海洋最底。
- 底图大陆边界下一层。
- 历史领土色块中层。
- 国家/地名标签上层。
- 当前高亮领土、事件影响范围与年份标记最上层。

### 5.3 尺寸约束

- 章节条目、事件卡片、筛选按钮、年份标记均使用固定或最小尺寸，防止内容变化引起跳动。
- 地图标签字号与地图缩放联动，但不超过两个字号档位，避免视觉噪声。

## 6. 数据模型

所有数据放在 `src/data/` 下，运行时只读，构建时校验。

### 6.1 Chapter（章节）

```ts
interface Chapter {
  id: string;
  order: number;
  title: string;
  subtitle: string;
  startYear: number;
  endYear: number;
  summary: string;
  sliceIds: string[];
}
```

### 6.2 EraSlice（年代切片）

```ts
interface EraSlice {
  id: string;
  year: number;
  label: string;
  summary: string;
  attributionId?: string;
  featuredEventIds: string[];
}
```

切片年份须在所属章节的年份范围内，按章节内顺序递增。

### 6.3 Polity（国家/帝国档案）

```ts
interface Polity {
  id: string;
  nameZh: string;
  nameEn?: string;
  type: 'empire' | 'kingdom' | 'republic' | 'colonial' | 'union' | 'cityState' | 'other';
  startYear?: number;
  endYear?: number;
  color: string;
  summary: string;
  relatedEventIds: string[];
}
```

### 6.4 Event（事件）

```ts
interface Event {
  id: string;
  year: number;
  startYear?: number;
  endYear?: number;
  title: string;
  summary: string;
  category: 'war' | 'treaty' | 'revolution' | 'colonization' | 'economy' | 'tech' | 'culture' | 'organization';
  regions: Region[];
  polityIds: string[];
  chapterId: string;
  importance: 1 | 2 | 3;
  featured?: boolean;
}
```

主题标签在界面上显示为：战争、条约/体系、革命/政变、殖民/去殖民化、经济/科技、文化/思想、国际组织。

### 6.5 AttributionFrame（领土归属帧）

```ts
interface AttributionEntry {
  polityId: string;
  countryCode: string;
  note?: string;
}

interface AttributionFrame {
  year: number;
  entries: AttributionEntry[];
}
```

`countryCode` 使用底图的现代国家/行政区代码。一个现代单元在同一帧内只能归属一个政体；无法明确归属时使用 `unclaimed`，界面显示为“无明确归属”。

### 6.6 地图底图与覆盖层

- 底图：使用可再分发的现代世界国家轮廓数据（Natural Earth 风格），作为领土归属着色的基础单元。
- 覆盖层：重要历史边疆与跨现代国界的帝国范围，使用额外 GeoJSON 或手绘边界近似线覆盖，例如奥斯曼、沙俄、大清、哈布斯堡、殖民帝国等。
- 所有覆盖层数据带 `sourceNote` 与 `approximate: true|false` 标记。

### 7.2 年代切片

- 约 35 个切片，覆盖 1300、1368、1453、1500、1648、1683、1789、1815、1871、1914、1919、1939、1945、1991、2026 等关键年份。
- 每个章节 2–4 个切片；切片之间尽量体现同一章节内的领土变化。
- 切片名称使用年份加短标签，例如 `1453 · 君士坦丁堡陷落`、`1648 · 威斯特伐利亚`。

### 7.3 事件编排

- 约 120 个事件，按章节分布，每章 6–12 个。
- 每个章节标记 3–6 个主线事件，进入地图下方卡片。
- 事件说明使用通史共识口径，不展开细节争议；需要说明的争议在事件详情中简短标注。
- 主题覆盖：
  - 战争与冲突：百年战争、三十年战争、拿破仑战争、一战、二战、冷战代理人战争等。
  - 条约与国际体系：威斯特伐利亚、维也纳、凡尔赛、雅尔塔、联合国等。
  - 革命与政体变化：法国大革命、1848、俄国革命、辛亥革命、去殖民化运动等。
  - 殖民与帝国：大航海、非洲瓜分、拉美独立、印度洋贸易、英帝国兴衰等。
  - 经济与科技：大航海贸易、工业革命、铁路与电报、大萧条、信息技术革命等。
  - 文化与思想：文艺复兴、宗教改革、启蒙运动、民族主义、社会主义传播等。
  - 国际组织：国联、联合国、欧盟、世贸组织等。

## 8. 技术架构

### 8.1 技术栈

- Vite
- React 18 + TypeScript
- D3-geo / D3-zoom 渲染与交互
- Vitest + Testing Library
- Playwright 冒烟测试

不使用外部地图瓦片，确保离线可用。

### 8.2 模块划分

```text
src/
  components/       界面组件
  data/             章节、切片、事件、国家、归属帧、覆盖层
  lib/
    mapRenderer.ts  投影、路径、缩放、高亮
    filter.ts       事件筛选与搜索
    validate.ts     数据校验逻辑（供测试复用）
    storage.ts      本地记忆当前章节/年份
  state/
    appReducer.ts   当前章节、年份、抽屉、播放、筛选状态
  styles/           羊皮纸主题 CSS
scripts/
  validate-data.ts  构建前数据校验入口
tests/
  data.test.ts
  app.test.tsx
  e2e.spec.ts
```

### 8.3 状态管理

使用 `useReducer` 加 Context，避免引入额外状态库。核心状态：

- 当前章节与切片
- 播放状态与播放计时
- 主题/地区筛选
- 搜索关键词
- 选中国家与事件
- 抽屉开关
- 地图动画中的高亮集合
- 错误与降级状态

### 8.4 数据流

1. 启动时加载静态数据并执行运行时校验。
2. 用户切换章节或切片，更新 `currentSlice`。
3. 地图渲染器根据切片读取归属帧与覆盖层，生成色块路径与高亮路径。
4. 用户点击国家，打开抽屉并展示国家档案与关联事件。
5. 用户点击事件，跳转到事件所属切片并高亮相关国家，再打开事件详情。
6. 播放模式按切片顺序自动推进，播放到章节末尾后停止。

## 9. 交互规范

### 9.1 时间轴与播放

- 底部年份滑块在所有切片间移动，不做逐年内插。
- 播放间隔默认每切片 3 秒；章节切换不重置播放状态，但停在章节末尾。
- 播放键有明确的暂停图标与状态提示。

### 9.2 地图

- 悬停国家时显示名称与当前归属，边界高亮。
- 点击国家打开右侧抽屉。
- 事件影响高亮使用朱砂红描边或半透明覆盖，与普通领土色块区分。
- 缩放范围限制在适合全球浏览与单区域查看之间，避免无限缩放。

### 9.3 筛选与搜索

- 主题筛选作用于事件卡片与完整事件列表，不改变地图。
- 搜索匹配章节、事件标题、国家名称与说明文字。
- 筛选后仍可点击事件跳转并高亮地图。

### 9.4 持久化

- 保存上次浏览的章节、切片与筛选条件到 `localStorage`。
- 刷新后恢复；数据版本变化时自动清空失效状态。

## 10. 边界与数据精度策略

1. 底图使用现代国界，作为历史归属的基础单元；这保证 20–21 世纪边界接近真实，较早时期则以现代领土为“着色单元”表达控制关系。
2. 对横跨多个现代国家的帝国，在整片现代领土单元上着色，并用覆盖层补充帝国内部边界和势力范围的近似线。
3. 殖民地、自治领、保护国等通过不同色阶或边线样式区分。
4. 无法准确归属的区域标为“无明确归属”，不强行填色。
5. 每个数据集记录 `sourceNote`；用户在“说明”页可查看主要参考来源与精度级别。
6. 涉及争议领土时使用中性表述，不把争议区作为地图强调对象。

## 11. 错误处理与降级

- 切片缺少归属数据时，地图显示“暂无边界数据”覆盖层，不显示空白地图。
- 单个切片加载失败时保留上一帧并显示提示，允许用户继续操作。
- 运行时校验发现结构性错误时，开发模式打印明确错误；构建模式阻止发布。
- 事件与国家引用缺失时，界面隐藏不可解析项，并在校验报告中列出。

## 12. 测试与质量

### 12.1 数据校验（Vitest）

- 章节顺序与年份连续。
- 切片年份唯一、在所属章节范围内并递增。
- 事件年份在所属章节范围内。
- 归属帧国家代码有效且每帧内无重复归属。
- 事件、国家、切片的引用均有目标。
- 必填字段完整，说明文字长度符合范围。

### 12.2 组件测试

- 页面能渲染章节列表、地图容器、时间轴和事件卡片。
- 切换章节与年份后状态正确更新。
- 筛选与搜索返回预期事件。
- 点击事件能打开抽屉并产生高亮集合。

### 12.3 端到端冒烟测试（Playwright）

- 打开页面后地图非空白。
- 依次切换 13 个章节，地图与事件区均正常更新。
- 点击 1914 事件后跳转正确切片并打开抽屉。
- 在桌面与手机视口各截图检查布局不溢出。

- 本地启动后能浏览 1300–2026 全部 13 个章节。
- 切换到任意切片，地图显示该年代领土归属，未出现空白地图。
- 点击事件可跳转对应切片并高亮影响地区。

- `npm run test` 与 `npm run build` 通过。

## 16. 风险

- 历史边界不可能完全精确，尤其是中世纪和殖民边界；通过“示意”标注和来源说明控制预期。
- 手工/半自动制作 35 个切片归属数据工作量大；实现时先完成覆盖全部章节的粗粒度帧，再逐章细化。
- 早期切片的现代领土归属可能与教科书“势力范围”概念不完全一致；使用国家/帝国色块加覆盖层表达。
- 动画性能取决于多边形数量；渲染层保留 Canvas 迁移方案，若 SVG 在高缩放时卡顿可切换渲染后端。
