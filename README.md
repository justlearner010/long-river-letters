# 长河来信 · Letters from the Long River

> **Say what you fear. Receive a letter from someone who lived through it.**
> 说出你害怕的事，收到一封来自亲历者的信。

送给每一个觉得世界正在失控的人。

---

## 这是什么

一个交互式地球，入口是一句提问：**2026 年的你，在担心什么？**

你选一个词——战争、瘟疫、贸易封锁、技术冲击——应用找到一个结构相似的历史时刻，然后展开一封信，写信的人真的经历过那件事。信末有一条因果链，从那一刻一直连到今天，每一跳都能点回地图上那一年。

信旁边放着一件那个时代的物件，可以拿在手里转。

**这不是安慰，是陪伴。** 信里不会说「一切都会好起来」，信里说的是：我在这里，这是我看见的，这是我当时还不知道的。

## 怎么跑起来

```bash
npm install
npm run dev          # 开发服务器 http://localhost:5173
```

生产构建：

```bash
npm run build        # 数据校验 → 类型检查 → 打包
npx vite preview     # 预览构建产物 http://localhost:4173
```

| 命令 | 作用 |
|---|---|
| `npm test` | 全部测试（93 个） |
| `npm run validate` | 数据一致性校验 |
| `npm run verify:models` | 检查 3D 物件是否符合规格 |
| `npm run generate:letters` | 生成信件正文（需要 `ANTHROPIC_API_KEY`） |

> **当前状态**：信件正文尚未生成。点进信件会看到人物小传与史料依据。跑一次 `generate:letters` 补全正文。

## 为什么不是 ChatGPT 套壳

生成文本容易伪造，也容易被怀疑。所以**信在整个作品里只占最小的一块**。

真正的承重结构是一套手工核对的历史数据：

| 数据 | 规模 | 说明 |
|---|---|---|
| 历史事件 | **126 个** | 每个都有起因、经过、影响与史料来源 |
| 疆域规则 | **466 条** | 现代国家轮廓 × 历史控制者，覆盖公元前 600 年至 2026 年 |
| 政权 | **307 个** | 含兴亡年代、地域、配色 |
| 因果链 | **28 条** | 手工标注，非模型生成 |
| 人物 | **18 位** | 6 位史有其人，12 位据史料重构的时代亲历者 |
| 时代物件 | **16 件** | Tripo3D 生成，逐件校验规格 |

生成信件时，模型拿到的只有**那一个事件的事实包**，并被硬性约束：**不得引入事实包以外的任何细节**。每条因果表述都标注为「一种理解视角」，而不是定论。

信件在构建时生成一次，人工审校后提交进仓库。**运行时零 API 调用，整个应用离线可用。**

## 技术要点

**前端**：React 18 + TypeScript + Vite。地图用 SVG + d3-geo 的正射投影渲染球体，不引入 WebGL。

**球体的取舍**：换成 Three.js 可以拿到真实光照与地形起伏，但会失去 `MapCountry` 的记忆化、CSS 过渡、原生悬停点击，以及中文标签的可选中与可访问性，包体还要再涨 330KB。而地球的立体感主要来自**球体轮廓 + 投影变形 + 明暗对比**——这三样 SVG 全能做。

**3D 物件**：`model-viewer`（BSD-3-Clause），动态加载，不拖累首屏。

**压缩**：16 件模型从 96.7 MB 压到 13.3 MB。规格是 **≤30k 三角面、≤1024² 贴图、仅 `KHR_mesh_quantization`**。

> ⚠️ **不能用 Draco 压缩**。`model-viewer` 加载 Draco 需要额外解码器，会引入运行时网络依赖，破坏离线可用的前提。

## 边界与判断

**疆域表述**：基于现代国家轮廓按历史控制者着色，主要帝国边界以近似覆盖表达。古代疆域争议远大于现代，因此规则中大量使用低优先级与不确定性注释，而非断言。**宁可显示得保守，不可显示得确定。**

**人物真实性**：代码库中没有任何结构化的人物数据，因此严格区分「史有其人」与「据史料重构的时代亲历者」，后者在界面上明确标注。**不允许编造具名历史人物。**

**因果表述**：每条因果链标注为一种理解视角。历史因果在学界有争议，把它说成必然既不准，也是一种谎言。
